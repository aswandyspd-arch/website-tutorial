Belajar HTML untuk Pemula: Panduan Lengkap 2025

Pak Lee · 15 Januari 2025 · ⏱ 8 menit baca

📑 Daftar Isi

    Apa itu HTML?

    HTML (HyperText Markup Language) adalah bahasa markup standar yang digunakan untuk membuat struktur halaman web. Setiap website yang Anda kunjungi—dari Google, YouTube, hingga Instagram—dibangun di atas HTML.

    Bayangkan HTML seperti kerangka rumah. CSS adalah cat dan dekorasinya, sedangkan JavaScript adalah listrik dan pipa air yang membuat rumah "hidup".

    Struktur Dasar HTML

    Setiap halaman HTML memiliki struktur dasar seperti berikut:

    HTML 
    <!DOCTYPE html>
<html lang="id">
<head>
  <meta charset="UTF-8">
  <title>Halaman Pertamaku</title>
</head>
<body>
  <h1>Hello, World!</h1>
  <p>Ini paragraf pertama saya.</p>
</body>
</html>

    Penjelasan Setiap Tag

    • <!DOCTYPE html> — memberi tahu browser ini HTML5
    • <html> — elemen root halaman
    • <head> — metadata (judul, charset, CSS)
    • <body> — konten yang tampil di layar

    Tag HTML yang Sering Digunakan

    Berikut tag dasar yang wajib Anda kuasai:

    TagFungsiContoh
    <h1>-<h6>Heading/judulH1 paling besar
    <p>ParagrafTeks biasa
    <a>LinkKlik di sini
    <img>GambarFoto
    <ul>/<ol>ListBullet/numbering

    Membuat Link dan Gambar

    Contoh membuat link ke Google dan menampilkan gambar:

    HTML 
    <a href="https://google.com" target="_blank">
  Kunjungi Google
</a>

<img src="foto.jpg" alt="Foto saya" width="300">
    💡 Tips: Selalu isi atribut alt pada gambar untuk aksesibilitas dan SEO.

    Contoh: Halaman Profil Sederhana

    Mari gabungkan semua yang telah kita pelajari:

    HTML 
    <!DOCTYPE html>
<html lang="id">
<head>
  <meta charset="UTF-8">
  <title>Profil Saya</title>
</head>
<body>
  <h1>Halo, saya Budi!</h1>
  <img src="budi.jpg" alt="Foto Budi" width="200">
  <p>Saya seorang pelajar yang sedang belajar coding.</p>
  <h2>Hobi Saya</h2>
  <ul>
    <li>Membaca buku</li>
    <li>Ngoding</li>
    <li>Bermain game</li>
  </ul>
  <a href="mailto:budi@email.com">Hubungi Saya</a>
</body>
</html>
    ⚠️ Perhatian: Jangan lupa menutup setiap tag! Tag yang tidak ditutup bisa menyebabkan tampilan berantakan.

    Langkah Selanjutnya

    Setelah menguasai HTML, Anda siap mempelajari:

    1. CSS — mempercantik tampilan
    2. JavaScript — membuat halaman interaktif
    3. Git & GitHub — menyimpan kode online
